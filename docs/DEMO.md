# 演示页面

这里整理了 AeroFold Lab / 云端纸翼实验室的主要界面截图，方便在 GitHub 项目页中快速了解作品效果。

## 距离挑战

距离挑战模式会优先评估纸飞机的航程表现，同时参考稳定性生成综合评分。用户可以调节机体参数和环境参数，观察航迹、落点和总分变化。

![距离挑战](images/demo-distance.png)

## 滞空挑战

滞空挑战模式更关注纸飞机在空中的停留时间。较合理的翼面积、折叠角、重心和发射角可以帮助纸飞机获得更平稳的滑翔表现。

![滞空挑战](images/demo-airtime.png)

## 飞行结果与 AI 飞行教练

每次发射后，右侧面板会生成总分、等级、距离、滞空、稳定性、升力、阻力、精准度和最佳记录。AI 飞行教练会根据当前结果给出下一步调参建议。

![飞行结果](images/demo-result.png)

## 主要交互

- 切换距离挑战、滞空挑战和精准降落模式。
- 拖动滑块调节翼面积、重心位置、折叠角、投掷力度、发射角和投掷方向。
- 开关翼梢小翼，比较稳定性和阻力变化。
- 调整风速和风向，观察环境因素对航迹的影响。
- 在 3D 实验场中查看纸飞机模型、预测航迹和落点。
- 切换中文、英文或双语界面。
